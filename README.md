# Godwin Ekanem — Software Engineering & AI Systems Portfolio

A professional portfolio presenting selected software engineering, AI application, and automation work. Featured systems link to structured case studies covering the problem, architecture, engineering decisions, reliability boundaries, result, and evidence.

## Stack

- Next.js 16.3.6 + React 19 + TypeScript
- Tailwind CSS 4
- Lucide React
- Vitest + Testing Library
- Vercel

## Local setup

```bash
corepack enable
pnpm install
pnpm dev
```

Optional: set `NEXT_PUBLIC_SITE_URL` to an explicit canonical production origin. On Vercel, the metadata falls back to Vercel's deployment hostname.

## Quality commands

```bash
pnpm test
pnpm lint
pnpm typecheck
pnpm build
```

## Portfolio scope

The homepage emphasizes Koya Lead Agent, RAG Application, Koya Proposal Studio, and the Real-Time Voice AI Agent. A separate automation progression connects invoice processing, operations reporting, Proposal Studio, Content Studio, and the Lead Agent as increasingly complete business systems.

The résumé is published as a first-class `/resume` web route, and Open Graph imagery is generated by Next.js through `app/opengraph-image.tsx`; no binary résumé or social-card assets are required in the repository.

## Deployment

Import this repository into Vercel and deploy `main`. Then verify `/`, `/resume`, every `/work/<slug>` route, `/sitemap.xml`, `/robots.txt`, and `/opengraph-image` on the production URL.
